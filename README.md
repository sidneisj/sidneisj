## 🚀 Projeto em Destaque

### Censo Escolar BI/Analytics

Projeto completo de BI/Analytics utilizando dados públicos do Censo Escolar/INEP, abrangendo o período de **2019 a 2025**.

O projeto inclui:

- exploração e validação dos dados;
- ETL e preparação dos dados com Python e Pandas;
- modelagem analítica na granularidade Escola × Ano;
- análises geográficas, administrativas e de infraestrutura;
- análise histórica dos indicadores educacionais;
- dashboards interativos desenvolvidos no Tableau;
- documentação técnica e práticas de governança de dados.
