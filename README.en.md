## 🚀 Featured Project

### Censo Escolar BI/Analytics

End-to-end BI/Analytics project using public data from the Brazilian School Census (INEP), covering the period from **2019 to 2025**.

The project includes:

- data exploration and validation;
- ETL and data preparation with Python and Pandas;
- analytical modeling at School × Year granularity;
- geographic, administrative and infrastructure analysis;
- historical analysis of educational indicators;
- interactive dashboards developed in Tableau;
- technical documentation and data governance practices.
